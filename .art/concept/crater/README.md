# Crater replacement

`source.png` is the generated concept. `Crater.png` is the approved 256x169
production crop, preserving the existing `Crater.png.meta` GUID, centered pivot,
and importer contract so `Crater.prefab` keeps its reference unchanged.

The redesign keeps the crater identity but applies the frozen A master style:
large matte basalt facets, three value bands, no contour, and restrained
hellfire orange visible only through the recessed magma core. Smoke, embers,
loose debris, ground plane, and baked shadow were intentionally excluded.
