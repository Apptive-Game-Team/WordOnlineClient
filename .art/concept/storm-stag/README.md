# Storm Stag charge impact

Production VFX candidate for the level-3-or-higher accelerated charge hit.

- `StormStagChargeImpact-source.png`: built-in ImageGen source output.
- `StormStagChargeImpact-256.png`: alpha-trimmed, 256 x 256 review asset.
- `StormStagChargeImpact-64-review.png`: readability check at gameplay scale.
- `StormStagChargeImpact-runtime-preview.png`: four-stage runtime timing QA board.
- Status: approved for this task and promoted into `Assets/Resources/Game/explode/`.

The effect uses a compressed central flash, paired antler-shaped lightning
branches, and broad backward shock shards. It intentionally contains no deer or
enemy body so the sprite can be overlaid at the collision point and flipped.
